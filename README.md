### 🚀 About Me

> *"Looking closely at how things are built, taken apart, and made better."*

I'm **Bao**, a self-taught developer from Vietnam who spends way too much time staring at binary and source code.

By trade, I build clean and functional applications; by curiosity, **I dive into disassemblers to read code that was never meant to be exposed, exposing the reality behind how systems and executables actually behave.** For me, crafting software and dissecting binaries are two sides of the same coin — it's all about curiosity, patience, and solving complex puzzles.

When I'm not tracing assembly or writing code, I'm usually gaming or listening to music.
